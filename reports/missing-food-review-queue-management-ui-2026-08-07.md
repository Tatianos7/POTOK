## Queue Management

The page reads rows from:

- `public.food_missing_review_queue`

Displayed row fields include:

- query;
- normalized query;
- status;
- classification;
- context;
- frequency;
- created/updated timestamps;
- suggested name/category/source;
- comment.

Filters:

- status;
- classification;
- context.

Sort order:

- `frequency desc`;
- `created_at desc`.

## Row Actions

Allowed status actions:

- `pending -> needs_research`
- `pending -> approved_for_food_draft`
- `needs_research -> approved_for_food_draft`
- `pending -> rejected`
- `needs_research -> rejected`
- `pending -> snoozed`
- `needs_research -> snoozed`

Editable fields:

- `comment`
- `suggested_name`
- `suggested_category`
- `suggested_source`

Status changes write:

- `status`
- `reviewer_id`
- `reviewed_at`
- editable review fields

`approved_for_food_draft` is disabled unless:

- `suggested_name` is non-blank;
- row classification is `missing_canonical_food`.

This mirrors the DB constraint and keeps broad/noise rows from becoming food drafts.
