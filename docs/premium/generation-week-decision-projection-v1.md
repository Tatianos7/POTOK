# Week selection decision projection

`projectGenerationWeekDecisionsRawV1` derives per-slot decision metadata from the same internally produced weighted selection receipt that chose the week. `createWeekDecisionProjectionPortV1` connects it to the existing selection-bound proposal and worker factories. The caller must supply the owned selector output, never client-submitted authority data.

Only strict weighted V2 and robust convenience-bound V3 selection receipts are accepted. First-feasible receipts are rejected. The producer verifies canonical receipt hashes, the nested optimization receipt and policy, request/input/manifest/revisions, raw selected-week hash, selected validation result, chosen ledger entries, search scope and budgets. It independently validates the selected week and checks exact slot coverage, candidate-pool digests, selected meal digests, source kinds and warning membership.

Every Graph V2 slot's `optimizationResultDigest` references the **actual whole-week optimization result digest**. It does not reference the slot projection receipt or claim an independently optimal local meal. Per-slot candidate-set and selected-candidate digests describe the actual pool and chosen meal. Separate `potok-generation-slot-week-decision-v1` receipts explicitly state `PROJECTED_FROM_WEEK_COMPARISON` and bind each slot to both the selection and optimization receipts. Their own digests use canonical safe-integer JSON `{contract, encoding: 'potok-generation-slot-week-decision-canonical-json-v1', decision: contentWithoutDigest}`; they are audit projections, not new optimization results.

Hash checks prove content binding, not origin, admission, approval or independent replay of all alternatives. This producer does not replace warning admission, metric-policy pinning or the independent final plan authority. The final validator still loads fresh authority and validates the exact proposal bytes before persistence; revoked authority blocks acceptance. The returned slot receipts are available to a future audit persistence adapter; this change does not install one.

Tests cover real strict/bounded engine receipts, deterministic projections, tampering/replay/pool membership rejection, duplicate JSON and first-feasible rejection. The integration runs computed week metrics through weighted selection, actual decision projection, Graph construction and independent worker validation without synthetic per-slot optimization hashes. Catalog, warning admission and final authority inputs remain explicitly synthetic fixtures. Unknown cooked yield and grams remain null; facts remain empty.

No SQL, live source publication, route, role, gateway, default switch or activation is added. Graph V1 remains unchanged. Cooking and recipe review remain deferred.
