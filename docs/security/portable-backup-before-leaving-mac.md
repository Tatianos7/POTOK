# Portable backup before losing Mac access

The restored 112-table copy has passed the joint rollback/content rehearsal. It need not stay powered on for generic development or synthetic CI. Owner-data persistent application checks still require a suitable owner-controlled computer and a restored full schema; this script does not remove that gate or apply any security changes.

Run `scripts/ops/portable-backup-macos.sh --prepare-portable-backup` with Bash on the owner's Mac. It reads only the existing POTOK_BACKUP_2026-10-24 archive and its original checksum manifest, refuses other platforms, creates a fresh private output directory and downloads the architecture-specific official age v1.3.2 release archive. SHA-256 digests are pinned to GitHub's published asset metadata. It extracts only age/age, then uses age's normal interactive passphrase mode. Passwords are never read into shell variables, arguments, history or files by this wrapper. Users must enter a non-empty passphrase to avoid age's optional displayed automatic passphrase generation. Keep the password separately.

After encryption it decrypts into a hash pipeline, never a new plaintext archive on disk, and requires byte equality to the original archive's SHA-256. It creates relative-filename ciphertext/plaintext checksum manifests and an owner-facing restore note. It deletes only its own freshly created temporary tool directory, then opens the new output folder in Finder. Source files, archive, Docker and hosted projects remain unchanged. The output folder is still local: PORTABLE_BACKUP_VERIFIED does not mean an external copy/upload has completed. Copy the whole folder to owner-controlled external storage or a private cloud and wait for the transfer to finish; verify the copied ciphertext checksum there when available. No archive, password or user records should be published to the repository.

Validation: Bash syntax and Linux platform refusal before backup access; release metadata SHA-256 for both Mac architectures; the downloaded arm64 archive's digest and age/age member checked. This Linux environment cannot execute the Darwin binary or complete the owner's interactive password/transfer steps. Actual success must come from the owner's Mac output and completed external transfer. A lost passphrase prevents recovery. The format is interoperable across Windows, Linux and macOS using age; it is not a Mac-only disk image.

Primary references: [age documentation and passphrase mode](https://github.com/FiloSottile/age), [age v1.3.2 official release](https://github.com/FiloSottile/age/releases/tag/v1.3.2).
